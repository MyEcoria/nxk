To implement in Rust

  1. screen.rs: glyph with a background color, frame (4 fills), centered and right-aligned text. Scales 3 and 4 already work.
  2. Colors: PANEL, EDGE, PRESS, BLUE, TERM_BG; memory bar in logo palette 3 and 5.
  3. Pages: header, tab bar, 5 pages. Full redraw on a page change; each second only the visible page's values.
  4. Touch: display reads input (KIND_TOUCH), turns the raw panel coordinates landscape; a tap is a press and release on the same zone. input has one queue: the shell's events would take touches from the screen.
  5. USB-C Ethernet: usbcon becomes a composite device, CDC-ACM + a CDC network function (ECM or NCM, to choose); net gets link usb0; one active link, usb0 first, wlan0 while usb0 has no DHCP address; usbcon::STATS reports the network function.
  6. Terminal: display reads the console traffic (a history of both directions, in usbcon or console, to choose), finds the nxk> prompts, applies the ANSI colors (the banner uses them) and wraps. Mask the passphrase of wifi connect. The directory in the prompt needs the shell to print it; a failed command is recognized by an errno name in its output or a shell marker (to choose).
  7. Actions, all in abi today: power::REBOOT/OFF, wifi::SCAN/RETRY/DISCONNECT.
  8. Logs: keep more than 3 lines (MSG_ROWS) and wrap them.
